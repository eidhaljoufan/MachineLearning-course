Pertemuan 6 — Perceptron

Perceptron merupakan model fundamental dalam ranah Jaringan Saraf Tiruan (Artificial Neural Network) yang berfungsi sebagai pengklasifikasi linear biner. Algoritma ini mensimulasikan cara kerja neuron biologis dalam memproses informasi melalui mekanisme pembobotan input untuk menghasilkan keputusan kategorikal.

Komponen Arsitektur Perceptron

Secara matematis, fungsionalitas Perceptron bergantung pada interaksi dinamis antara beberapa komponen variabel primer berikut:

  • Input ($x$): Representasi fitur numerik yang diekstraksi dari dataset sebagai sinyal masuk.
  • Weights ($w$): Parameter penentu bobot kepentingan atau kontribusi tiap fitur terhadap hasil akhir.
  • Bias ($b$): Komponen konstan yang memungkinkan pergeseran fungsi aktivasi untuk mencapai fleksibilitas model.
  • Fungsi Aktivasi: Transformasi non-linear (biasanya Heaviside Step Function) yang mengonversi hasil komputasi menjadi output biner.

Implementasi Sederhana dengan Python

Kode berikut menunjukkan logika inti Perceptron dalam mempelajari pola linear. Model ini secara iteratif menyesuaikan bobotnya berdasarkan selisih antara nilai prediksi dan label aktual hingga mencapai konvergensi. 

class Perceptron:
    def __init__(self, learning_rate=0.1, epochs=10):
        self.lr = learning_rate
        self.epochs = epochs
        self.weights = [0.0, 0.0]
        self.bias = 0.0

    def predict(self, inputs):
        # Perhitungan weighted sum (Z = W.X + b)
        summation = sum(w * i for w, i in zip(self.weights, inputs)) + self.bias
        return 1 if summation > 0 else 0

    def train(self, training_data, labels):
        for _ in range(self.epochs):
            for inputs, label in zip(training_data, labels):
                prediction = self.predict(inputs)
                # Aturan pembaharuan bobot (Gradient Descent Sederhana)
                error = label - prediction
                self.weights = [w + self.lr * error * i for w, i in zip(self.weights, inputs)]
                self.bias += self.lr * error

# Dataset Gerbang Logika AND
data = [[0, 0], [0, 1], [1, 0], [1, 1]]
labels = [0, 0, 0, 1]

model = Perceptron()
model.train(data, labels)

# Validasi Model
print("Hasil Prediksi Gerbang AND:")
for x in data:
    print(f"Input: {x} -> Prediksi: {model.predict(x)}")

Analisis Keterbatasan dan Decision Boundary

Berdasarkan visualisasi Decision Boundary, Perceptron bekerja dengan menarik garis lurus (hiperplane) untuk memisahkan dua kelas data. Namun, model ini memiliki batasan teoretis yang signifikan:

  • Linear Separability: Perceptron hanya mampu mengonvergensi solusi jika data dapat dipisahkan secara linear sempurna.
  • Non-Linear Problems: Model ini gagal dalam memetakan fungsi kompleks seperti gerbang logika XOR, yang secara historis memicu transisi evolusioner menuju Multi-Layer Perceptron (MLP) dan era Deep Learning.
