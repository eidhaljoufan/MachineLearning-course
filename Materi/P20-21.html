Pertemuan 20 & 21 — Object Segmentation

Object Segmentation adalah task lanjutan dalam computer vision yang bertujuan untuk memisahkan objek secara presisi hingga ke tingkat piksel. Berbeda dengan object detection yang hanya memberikan bounding box, segmentation mampu menentukan bentuk asli objek dengan akurasi tinggi.

Segmentasi objek sangat penting dalam aplikasi yang membutuhkan pemahaman visual yang detail, seperti medical imaging, autonomous driving, robotics, dan image editing. Pada pertemuan ini, pembahasan difokuskan pada konsep dasar, perbandingan dengan task visi komputer lain, serta pengenalan metode dan alur praktik object segmentation.

Posisi Object Segmentation dalam Visi Komputer

Dalam visi komputer, terdapat beberapa task utama yang memiliki tingkat kompleksitas dan keluaran yang berbeda. Object segmentation merupakan task dengan tingkat detail tertinggi karena bekerja pada level piksel.

Perbandingan Task dalam Visi Komputer

Tugas Visi Komputer Keluaran Tingkat Detail
Image Classification
(Klasifikasi Gambar)		 Label tunggal untuk seluruh gambar Menjawab pertanyaan apa yang ada di dalam gambar (misalnya: "Kucing").
Object Detection
(Deteksi Objek)		 Bounding box (kotak pembatas) di sekitar setiap objek beserta label kelasnya. Menjawab apa dan di mana objek berada (misalnya: kotak di sekeliling kucing).
Object Segmentation
(Segmentasi Objek)		 Segmentation mask yang menentukan batas objek secara presisi pada tingkat piksel. Menentukan bentuk dan batas pasti objek (misalnya: setiap piksel tubuh kucing diwarnai).

Apa itu Object Segmentation?

Object segmentation bertujuan untuk mengklasifikasikan setiap piksel dalam sebuah gambar. Setiap piksel ditentukan apakah termasuk ke dalam objek tertentu atau ke background. Dengan pendekatan ini, sistem dapat memahami struktur visual gambar secara jauh lebih detail dibanding detection.

Jenis-Jenis Segmentasi

  • Semantic Segmentation:

    Mengklasifikasikan setiap piksel ke dalam suatu kelas, tetapi tidak membedakan antar instance objek yang sama. Semua objek dengan kelas sama akan memiliki warna mask yang sama.

  • Instance Segmentation:

    Membedakan setiap instance objek meskipun berasal dari kelas yang sama. Contoh: dua kucing akan memiliki mask yang berbeda.

  • Panoptic Segmentation:

    Kombinasi antara semantic dan instance segmentation. Semua piksel diklasifikasikan, dan setiap instance juga dibedakan secara individual.

Algoritma dan Model untuk Object Segmentation

Berbagai algoritma deep learning telah dikembangkan untuk menyelesaikan task segmentation. Sebagian besar metode modern menggunakan arsitektur convolutional neural networks (CNN).

  • FCN (Fully Convolutional Network):

    Arsitektur awal untuk semantic segmentation yang mengganti fully connected layer dengan convolution.

  • U-Net:

    Banyak digunakan pada medical imaging, memiliki encoder–decoder dengan skip connections.

  • Mask R-CNN:

    Extension dari Faster R-CNN yang menambahkan branch khusus untuk segmentation mask.

  • YOLOv8 Segmentation:

    Versi YOLO yang mendukung segmentation dengan kecepatan tinggi dan akurasi baik.

Alur Umum Object Segmentation

  1. Input Image:

    Gambar dimasukkan ke dalam model segmentation.

  2. Feature Extraction:

    Model CNN mengekstraksi fitur visual dari gambar.

  3. Pixel-wise Prediction:

    Setiap piksel diprediksi kelas atau instance-nya.

  4. Segmentation Mask:

    Hasil akhir berupa mask yang menunjukkan area objek.

Aplikasi Object Segmentation

  • Medical Imaging:

    Segmentasi organ atau tumor pada CT-scan dan MRI.

  • Autonomous Driving:

    Memahami jalan, kendaraan, pejalan kaki secara detail.

  • Industrial Inspection:

    Mendeteksi cacat produk secara presisi.

  • Image Editing:

    Background removal dan object manipulation.

  • Robotics:

    Object grasping dan navigation berbasis visual.

Tujuan Pembelajaran Pertemuan 20 – 21

Setelah mempelajari materi ini, diharapkan mampu memahami perbedaan mendasar antara classification, detection, dan segmentation, mengenali jenis-jenis object segmentation, serta memahami alur kerja dan penerapannya sebelum masuk ke tahap praktik implementasi menggunakan model deep learning.

Alur Pengerjaan Proyek Real-Time Detection Gunting-Batu-Kertas

Proyek ini membahas alur pengerjaan proyek real-time object detection yang telah dilakukan, yaitu sistem deteksi Gunting – Batu – Kertas menggunakan dataset buatan sendiri. Fokus pembahasan diarahkan pada proses persiapan data, pelabelan, training model, hingga pengujian deteksi secara real-time menggunakan kamera.

Gambaran Umum Proyek

Sistem yang dibangun bertujuan untuk mengenali gesture tangan gunting, batu, dan kertas secara langsung melalui webcam. Model dilatih menggunakan dataset kustom yang dibuat sendiri dan diberi label menggunakan platform Roboflow.

Spesifikasi Dataset

Jumlah Data ± 1000 gambar
Sumber Data Dataset download dari kumpulan gambar Gunting-Batu-Kertas di roboflow/kaggle
Pelabelan Roboflow (Bounding Box Annotation)
Format Dataset YOLO Format
  1. Pengumpulan Dataset

    Data dikumpulkan secara mandiri dengan mengambil gambar gesture tangan gunting, batu, dan kertas. Variasi posisi tangan, jarak kamera, pencahayaan, dan sudut pengambilan diperhatikan agar model tidak overfitting.

  2. Upload Dataset ke Roboflow

    Seluruh gambar mentah diunggah ke platform Roboflow untuk memudahkan proses anotasi dan manajemen dataset.

  3. Proses Pelabelan (Annotation)

    Setiap gambar diberi bounding box sesuai kelas gesture (gunting, batu, atau kertas). Pelabelan dilakukan secara konsisten untuk menjaga kualitas dataset.

  4. Preprocessing dan Augmentasi Data

    Roboflow digunakan untuk melakukan augmentasi seperti rotasi, perubahan brightness, flipping, dan scaling. Tahap ini bertujuan meningkatkan generalisasi model saat training.

  5. Export Dataset ke Format YOLO

    Dataset diekspor dalam format YOLO yang berisi direktori train, val, dan test, serta file data.yaml sebagai konfigurasi dataset.

  6. Training Model Object Detection

    Model YOLO dilatih menggunakan dataset tersebut. Proses training melibatkan penentuan epoch, batch size, dan pemilihan model (misalnya YOLOv8). Semakin banyak epoch, semakin lama waktu training, tetapi berpotensi meningkatkan akurasi.

  7. Evaluasi Hasil Training

    Model dievaluasi menggunakan metrik seperti precision, recall, dan mAP. Visualisasi hasil deteksi pada data validasi juga diperiksa untuk memastikan bounding box sudah sesuai.

  8. Implementasi Real-Time Detection

    Model hasil training digunakan untuk inference real-time melalui webcam. Sistem menampilkan bounding box dan label kelas secara langsung saat gesture tangan terdeteksi.

Hasil yang Diharapkan

Dengan mengikuti alur pengerjaan ini, sistem diharapkan mampu mendeteksi gesture gunting, batu, dan kertas secara real-time dengan tingkat akurasi yang stabil dan respons yang cepat.
