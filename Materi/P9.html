Pertemuan 9 — Evaluasi Model Machine Learning

Evaluasi Model merupakan tahapan kritis untuk menentukan sejauh mana model Machine Learning mampu melakukan generalisasi terhadap data yang belum pernah dilihat sebelumnya (unseen data). Tanpa evaluasi yang komprehensif, model berisiko memberikan hasil yang tampak akurat namun gagal total saat diimplementasikan pada skenario dunia nyata.

Masalah Utama: Overfitting dan Underfitting

Dalam proses pelatihan, model seringkali terjebak dalam dua kondisi ekstrem yang merusak performa prediktifnya:

  • Overfitting: Kondisi di mana model terlalu "menghafal" detail dan noise pada data latih secara berlebihan. Akurasi pada data latih sangat tinggi, namun akurasi pada data uji sangat rendah.
  • Underfitting: Terjadi ketika model terlalu sederhana sehingga gagal menangkap pola fundamental dalam data. Akurasi rendah baik pada data latih maupun data uji.
  • The Bias-Variance Tradeoff: Tantangan untuk menyeimbangkan antara Bias (error karena asumsi yang terlalu simpel) dan Variance (sensitivitas berlebih terhadap fluktuasi data).

Teknik Evaluasi dan Validasi Data

Untuk memitigasi masalah di atas, kita menggunakan berbagai metode pembagian data (data splitting) guna menguji ketangguhan model secara objektif:

  1. Hold-out Method:

    Metode paling sederhana dengan membagi dataset secara permanen menjadi dua bagian: Training Set (untuk melatih) dan Test Set (untuk pengujian akhir). Kelemahannya adalah hasil evaluasi sangat bergantung pada bagaimana data tersebut dipisahkan.

  2. Train-Validation-Test Split:

    Pengembangan dari Hold-out dengan menambahkan Validation Set. Data validasi digunakan untuk menyetel hiperparameter selama proses pelatihan, sementara data uji tetap "suci" untuk evaluasi akhir.

  3. Cross Validation (K-Fold):

    Membagi data menjadi k bagian (fold). Model dilatih k kali, di mana setiap kali satu bagian menjadi data uji dan sisanya menjadi data latih. Hasil akhirnya adalah rata-rata dari seluruh iterasi, sehingga lebih stabil.

  4. Time Series Cross-Validation:

    Teknik khusus untuk data yang bergantung pada waktu (seperti harga saham). Kita tidak bisa mengacak data secara random; kita harus menggunakan data masa lalu untuk memprediksi data masa depan secara berurutan (Rolling Window).

  5. Nested Cross-Validation:

    Metode evaluasi tingkat lanjut yang menggunakan dua lapisan Cross-Validation. Lapisan dalam (inner loop) untuk memilih parameter terbaik, dan lapisan luar (outer loop) untuk mengukur performa generalisasi model secara keseluruhan.

Metrik Evaluasi Utama

Selain teknik pembagian data, kita menggunakan metrik numerik untuk mengukur presisi prediksi:

No. Metrik Fungsi Utama Konteks Penggunaan
1 Accuracy Rasio prediksi benar terhadap total data. Dataset dengan kelas seimbang.
2 Precision & Recall Mengukur ketepatan dan kelengkapan prediksi. Klasifikasi dengan kelas tidak seimbang (Imbalanced).
3 F1-Score Rata-rata harmonik antara Precision dan Recall. Keseimbangan antara kesalahan Tipe I dan Tipe II.
4 MSE / RMSE Mengukur rata-rata kuadrat kesalahan. Evaluasi model Regresi.
