Pertemuan 1 — Pengenalan Machine Learning

Pada pertemuan ini dibahas tentang dasar-dasar machine learning, dan pengenalan bahasa pemrograman Python yang sering digunakan dalam machine learning. Untuk pemahaman konsep machine learning, kita juga akan membahas perbedaan antara Artificial Intelligence (AI), Machine Learning (ML), dan Deep Learning (DL).

Kategori Definisi Fokus Contoh
AI Bidang luas yang mencakup semua teknik yang memungkinkan mesin untuk meniru kecerdasan manusia. Ini mencakup berbagai teknologi, termasuk ML dan DL, serta metode lain seperti sistem berbasis aturan dan algoritma pencarian. Pembuatan sistem yang dapat berpikir, belajar, dan beradaptasi seperti manusia. Asisten virtual (Siri, Alexa), catur (Deep Blue), dan robotika.
ML Sub-bidang dari AI yang fokus pada pengembangan algoritma yang memungkinkan komputer untuk belajar dari data dan membuat keputusan atau prediksi tanpa diprogram secara eksplisit. Pengembangan model dari data yang memungkinkan komputer untuk "belajar" dari pengalaman. Pengenalan wajah, filter spam email, dan rekomendasi produk e-commerce.
DL Sub-bidang dari ML yang menggunakan jaringan saraf tiruan (neural networks) dengan banyak lapisan (deep) untuk menganalisis data secara lebih mendalam dan menangkap pola yang kompleks. Penggunaan jaringan saraf yang lebih dalam untuk menangani data yang sangat besar dan kompleks, serta mengenali pola yang lebih rumit. Pengenalan suara sangat akurat, pemrosesan gambar, analisis video, dan mobil otonom.

Machine Learning

Machine Learning (ML) merupakan disiplin ilmu yang memfokuskan pada pengembangan model stokastik yang mampu mengidentifikasi pola laten dalam data tanpa instruksi eksplisit.
Secara teoretis, ML diklasifikasikan menjadi tiga paradigma utama:

  1. Supervised Learning

    Paradigma ini beroperasi pada dataset yang memiliki label/target eksplisit (y = f(x)). Tujuannya adalah untuk mengestimasi fungsi pemetaan antara variabel input (x) dan output (y).Klasifikasi: Prediksi variabel diskrit (Contoh: Diagnosa medis, deteksi fraud).Regresi: Prediksi variabel kontinu (Contoh: Estimasi nilai properti, fluktuasi ekonomi).

  2. Unsupervised Learning

    Paradigma ini beroperasi pada dataset yang tidak memiliki label. Fokus utamanya adalah mengekstraksi struktur intrinsik atau representasi fitur dari data. Clustering: Mengelompokkan observasi berdasarkan metrik kemiripan (Contoh: Segmentasi pasar). Dimensionality Reduction: Mereduksi jumlah variabel tanpa menghilangkan informasi krusial (Contoh: Teknik PCA).

  3. Reinforcement Learning

    Pendekatan ini berbasis pada interaksi dinamis antara Agen dan Lingkungan. Pembelajaran terjadi melalui mekanisme feedback berupa reward (imbalan) atau penalty (hukuman) guna mencapai kebijakan (policy) yang optimal. Aplikasi: Optimasi robotika, sistem kendali otonom, dan game theory.

Python

Python sebagai Lingkungan Komputasi Saintifik Dalam konteks pengembangan Artificial Intelligence, Python didefinisikan sebagai bahasa pemrograman tingkat tinggi yang bersifat interpreted dan multipurpose. Bagi kalangan akademisi, Python bukan sekadar alat koding, melainkan standar de facto untuk riset karena memiliki karakteristik berikut:

  • Sintaksis Ekspresif: Memungkinkan peneliti mentransformasikan rumus matematis kompleks menjadi kode program dengan tingkat keterbacaan (readability) yang superior.

  • Ekosistem Library Komprehensif: Ketersediaan pustaka seperti NumPy untuk aljabar linear, Pandas untuk manipulasi data terstruktur, dan Scikit-learn sebagai standar baku implementasi algoritma ML.

  • Interoperabilitas: Kemampuan Python untuk berintegrasi dengan bahasa tingkat rendah seperti C/C++ guna mengejar efisiensi eksekusi pada komputasi skala besar.
