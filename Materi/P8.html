Pertemuan 8 — Logistic Regression

Logistic Regression adalah algoritma pembelajaran mesin yang digunakan untuk memecahkan masalah klasifikasi, di mana variabel target bersifat kategorikal. Berbeda dengan Linear Regression yang memprediksi nilai kontinu, Logistic Regression menggunakan fungsi logistik (Sigmoid) untuk mengonversi output linear menjadi nilai probabilitas antara 0 dan 1.

Prinsip Dasar Logistqic Regression

Secara metodologis, algoritma ini tidak mencari garis lurus yang melewati data, melainkan mencari kurva "S" yang paling optimal untuk memisahkan kelas-kelas data berdasarkan probabilitas:

  • Fungsi Sigmoid:

    Persamaan matematis yang memetakan angka real apa pun ke dalam rentang [0, 1]. Rumus: f(z) = 1 / (1 + e-z).

  • Decision Threshold:

    Ambang batas (biasanya 0.5) yang menentukan apakah suatu data masuk ke Kelas A atau Kelas B berdasarkan nilai probabilitasnya.

  • Logit Link Function:

    Transformasi linear dari probabilitas yang memungkinkan hubungan linear antara fitur dan log-odds dari variabel target.

Langkah-Langkah Proses Pemodelan

Implementasi Logistic Regression dalam riset akademik mengikuti alur sistematis berikut untuk memastikan validitas model klasifikasi:

  1. Linear Combination:

    Menghitung kombinasi linear dari fitur menggunakan koefisien β (serupa dengan Linear Regression): z = β0 + β1x1 + ...

  2. Probability Mapping:

    Melewatkan nilai z ke dalam fungsi Sigmoid untuk mendapatkan estimasi probabilitas P(y=1|x).

  3. Log-Loss Optimization:

    Melatih model dengan meminimalkan fungsi Cost yang disebut Cross-Entropy Loss atau Log-Loss untuk menyesuaikan koefisien β secara akurat.

  4. Performance Evaluation:

    Mengukur kinerja menggunakan Confusion Matrix untuk menghitung nilai Akurasi, Presisi, dan Recall.

Tipe-Tipe Logistic Regression

Algoritma ini dapat diklasifikasikan berdasarkan jumlah dan sifat kategori pada variabel dependennya:

No. Tipe Karakteristik Output Contoh Kasus
1 Binary Logistic Hanya memiliki dua kategori (Biner). Prediksi Email: Spam atau Bukan Spam.
2 Multinomial Logistic Memiliki tiga kategori atau lebih tanpa urutan. Prediksi jenis tanaman: Spesies A, B, atau C.
3 Ordinal Logistic Memiliki tiga kategori atau lebih dengan urutan tertentu. Rating Kepuasan: Rendah, Sedang, Tinggi.
