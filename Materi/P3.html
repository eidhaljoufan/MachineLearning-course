Pertemuan 3 — Supervised Learning

Supervised Learning merupakan paradigma pembelajaran mesin yang paling umum digunakan dalam aplikasi praktis. Dalam pendekatan ini, model dilatih menggunakan dataset yang telah dilabeli, di mana setiap input (X) memiliki output (Y) yang sudah diketahui. Tujuan utamanya adalah membangun fungsi pemetaan f(X) → Y yang dapat memprediksi output untuk data baru yang belum pernah dilihat sebelumnya.

Karakteristik Supervised Learning

Supervised Learning memiliki beberapa karakteristik fundamental yang membedakannya dari paradigma pembelajaran lainnya:

  • Dataset Berlabel:

    Setiap observasi dalam dataset memiliki pasangan input-output (X, Y) yang eksplisit, memungkinkan model untuk belajar dari contoh yang telah dikoreksi.

  • Pembelajaran Terarah:

    Model menerima feedback langsung melalui perbandingan antara prediksi dengan label sebenarnya, sehingga dapat mengoptimalkan parameter secara iteratif.

  • Generalisasi:

    Kemampuan model untuk membuat prediksi akurat pada data baru yang tidak terlihat selama fase pelatihan merupakan indikator kesuksesan utama.

  • Fungsi Loss:

    Proses pembelajaran dikendalikan oleh minimisasi fungsi kerugian (loss function) yang mengukur deviasi antara prediksi model dengan nilai aktual.

Kategorisasi Supervised Learning

Berdasarkan sifat variabel target (Y), Supervised Learning diklasifikasikan menjadi dua kategori utama yang memiliki perbedaan fundamental dalam hal output dan metode evaluasi:

Aspek Klasifikasi Regresi
Definisi Memetakan input ke dalam kategori atau kelas diskrit yang telah ditentukan sebelumnya. Memetakan input ke nilai kontinu dalam rentang numerik tertentu.
Tipe Output Nilai diskrit (kategorikal) seperti label kelas atau probabilitas kelas. Nilai kontinu (numerik) dalam domain bilangan riil.
Tujuan Memisahkan data ke dalam kategori atau kelas yang telah ditentukan sebelumnya dengan memaksimalkan akurasi klasifikasi. Memperkirakan hubungan antara variabel input (fitur) dan variabel output (label) yang berupa nilai kontinu.
Contoh Kasus Deteksi spam email (spam/non-spam), klasifikasi gambar hewan (kucing/anjing), diagnosa penyakit berdasarkan gejala. Prediksi harga rumah berdasarkan fitur properti, estimasi suhu udara masa depan, proyeksi penjualan produk.
Metrik Evaluasi Accuracy, Precision, Recall, F1-Score, Confusion Matrix, AUC-ROC. Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), R-squared (R²).

1. Klasifikasi (Classification)

Klasifikasi adalah tugas untuk memisahkan data ke dalam kategori atau kelas yang telah ditentukan sebelumnya. Model klasifikasi mempelajari batas keputusan (decision boundary) yang memisahkan kelas-kelas dalam ruang fitur.

Tujuan: Memisahkan data ke dalam kategori atau kelas yang telah ditentukan sebelumnya dengan memaksimalkan akurasi prediksi kelas.

Output: Output dari model klasifikasi adalah nilai diskrit, yaitu kelas atau kategori tertentu. Contohnya, dalam klasifikasi biner, outputnya bisa berupa "0" atau "1", "spam" atau "non-spam", "positif" atau "negatif".

Contoh Aplikasi: Mendeteksi apakah email adalah spam atau tidak, mengklasifikasikan gambar sebagai kucing atau anjing, memprediksi jenis penyakit berdasarkan gejala pasien, identifikasi fraud dalam transaksi keuangan.

Algoritma Populer:

  • K-Nearest Neighbors (KNN):

    Mengklasifikasikan data berdasarkan mayoritas kelas dari K tetangga terdekat dalam ruang fitur.

  • Decision Tree:

    Membangun struktur pohon keputusan berdasarkan aturan pemisahan fitur untuk mencapai klasifikasi.

  • Support Vector Machine (SVM):

    Mencari hyperplane optimal yang memaksimalkan margin pemisah antar kelas.

  • Naive Bayes:

    Menerapkan teorema Bayes dengan asumsi independensi antar fitur untuk menghitung probabilitas kelas.

  • Random Forest:

    Ensemble learning yang menggabungkan multiple decision trees untuk meningkatkan akurasi dan mengurangi overfitting.

  • Neural Networks:

    Menggunakan arsitektur jaringan saraf tiruan dengan multiple layers untuk pembelajaran representasi kompleks.

2. Regresi (Regression)

Regresi adalah tugas untuk memperkirakan hubungan matematis antara variabel input (fitur) dan variabel output (label) yang berupa nilai kontinu. Model regresi menghasilkan fungsi yang dapat memprediksi nilai numerik dalam rentang tertentu.

Tujuan: Memperkirakan hubungan antara variabel input (fitur) dan variabel output (label), yang berupa nilai kontinu, serta meminimalkan error prediksi.

Output: Output dari model regresi adalah nilai numerik yang kontinu. Ini berarti model memprediksi nilai dalam rentang tertentu, bukan kategori. Output dapat berupa bilangan real positif, negatif, atau desimal.

Contoh Aplikasi: Memprediksi harga rumah berdasarkan fitur seperti luas tanah, jumlah kamar, dan lokasi, memperkirakan suhu udara di masa depan berdasarkan data historis, proyeksi nilai saham, estimasi permintaan produk.

Algoritma Populer:

  • Linear Regression:

    Membangun hubungan linear antara variabel independen dan dependen menggunakan metode least squares.

  • Polynomial Regression:

    Ekstensi dari linear regression yang dapat menangkap hubungan non-linear melalui transformasi polinomial fitur.

  • Ridge Regression (L2 Regularization):

    Menambahkan penalty term untuk mengurangi kompleksitas model dan mencegah overfitting.

  • Lasso Regression (L1 Regularization):

    Regularisasi yang dapat melakukan feature selection dengan membuat beberapa koefisien menjadi nol.

  • Support Vector Regression (SVR):

    Adaptasi SVM untuk tugas regresi dengan mencari fungsi yang berada dalam margin toleransi error.

  • Decision Tree Regression:

    Menggunakan struktur pohon untuk membagi ruang fitur dan memprediksi nilai kontinu pada setiap leaf node.

Proses Supervised Learning

Implementasi Supervised Learning mengikuti alur sistematis yang terdiri dari beberapa fase kunci:

  1. Data Collection & Labeling:

    Pengumpulan dataset dengan label yang akurat dan representatif terhadap distribusi masalah nyata.

  2. Data Splitting:

    Pemisahan dataset menjadi training set (70-80%), validation set (10-15%), dan test set (10-15%) untuk evaluasi objektif.

  3. Model Training:

    Algoritma mempelajari pola dari training data dengan mengoptimalkan fungsi loss melalui iterasi.

  4. Model Validation:

    Evaluasi performa model pada validation set untuk tuning hyperparameter dan mencegah overfitting.

  5. Model Testing:

    Evaluasi final pada test set yang sepenuhnya unseen untuk mengukur kemampuan generalisasi model.

  6. Prediction:

    Deployment model untuk melakukan inferensi pada data baru dalam environment produksi.

Keuntungan Supervised Learning

  • Akurasi Tinggi:

    Dengan data training yang berkualitas dan representatif, model dapat mencapai tingkat akurasi yang sangat baik.

  • Interpretabilitas:

    Beberapa algoritma seperti Decision Tree dan Linear Regression memiliki transparansi dalam proses pengambilan keputusan.

  • Aplikabilitas Luas:

    Dapat diterapkan pada berbagai domain seperti finance, healthcare, marketing, dan computer vision.

  • Metrik Evaluasi Jelas:

    Terdapat berbagai metrik standar yang well-established untuk mengukur performa model secara objektif.

Keterbatasan Supervised Learning

  • Ketergantungan pada Labeled Data:

    Membutuhkan dataset berlabel dalam jumlah besar yang seringkali mahal dan time-consuming untuk diperoleh.

  • Overfitting:

    Model dapat terlalu fit pada training data sehingga performa pada data baru menurun drastis.

  • Bias dalam Data:

    Jika training data tidak representatif atau mengandung bias, model akan mereproduksi bias tersebut dalam prediksi.

  • Keterbatasan Generalisasi:

    Model mungkin tidak dapat beradaptasi dengan baik terhadap data yang memiliki distribusi berbeda dari training data (concept drift).

  • Computational Cost:

    Pelatihan model pada dataset besar dengan algoritma kompleks memerlukan resource komputasi yang signifikan.
