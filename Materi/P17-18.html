Pertemuan 17 & 18 — Object Detection & Deteksi APD

Object Detection adalah tugas computer vision yang bertujuan untuk mengidentifikasi dan melokalisasi objek dalam gambar atau video. Berbeda dengan image classification yang hanya memberikan label untuk keseluruhan gambar, object detection menghasilkan bounding box yang menunjukkan posisi spesifik dari setiap objek yang terdeteksi beserta label kelasnya. Tugas ini menggabungkan dua permasalahan utama, yaitu classification (menentukan objek apa yang ada) dan localization (menentukan lokasi objek).

Konsep Dasar Object Detection

Object detection menghasilkan output berupa beberapa bounding box, di mana setiap kotak didefinisikan oleh koordinat (x, y, width, height), label kelas, dan confidence score yang menunjukkan seberapa yakin model bahwa objek tersebut benar-benar ada di dalam kotak tersebut. Model harus mampu mendeteksi banyak objek dalam satu gambar, menangani objek dengan berbagai skala dan rasio aspek, serta membedakan objek yang saling tumpang tindih.

Arsitektur Object Detection

Model object detection dapat dikategorikan menjadi dua paradigma utama:

  • Two-Stage Detectors:

    Proses deteksi dipisahkan menjadi tahap region proposal dan classification. Tahap pertama menghasilkan kandidat lokasi objek, kemudian tahap kedua melakukan klasifikasi dan penyempurnaan lokasi tersebut. Contoh: R-CNN, Fast R-CNN, Faster R-CNN. Umumnya memiliki akurasi lebih tinggi tetapi waktu pemrosesan lebih lambat.

  • One-Stage Detectors:

    Melakukan deteksi dalam satu kali proses. Bounding box dan kelas objek diprediksi secara langsung dari fitur gambar tanpa tahap region proposal terpisah. Contoh: YOLO (You Only Look Once), SSD (Single Shot Detector), RetinaNet. Lebih cepat dan cocok untuk aplikasi real-time, dengan selisih akurasi yang semakin kecil berkat inovasi terbaru.

YOLO (You Only Look Once)

YOLO merupakan salah satu arsitektur object detection paling populer karena mampu menyeimbangkan kecepatan dan akurasi. YOLO membagi gambar menjadi beberapa sel grid, di mana setiap sel bertanggung jawab untuk memprediksi bounding box dan probabilitas kelas untuk objek yang pusatnya berada di dalam sel tersebut. Arsitektur ini sangat cepat karena menggunakan pendekatan satu tahap dan mampu melakukan deteksi secara real-time.

Komponen Kunci YOLO:

  • Grid Division:

    Gambar dibagi menjadi grid berukuran S×S. Setiap sel grid memprediksi beberapa bounding box dan confidence score.

  • Bounding Box Prediction:

    Setiap kotak diprediksi menggunakan lima nilai, yaitu x dan y sebagai koordinat pusat, w dan h sebagai lebar dan tinggi, serta confidence score.

  • Class Prediction:

    Setiap sel grid juga memprediksi probabilitas kelas bersyarat untuk sejumlah kelas objek.

  • Non-Maximum Suppression (NMS):

    Tahap pasca-pemrosesan untuk menghilangkan deteksi ganda. Bounding box dengan tingkat tumpang tindih tinggi dan confidence score lebih rendah akan dihapus.

YOLO Versions: YOLO berkembang dari versi awal hingga YOLOv8 dan versi terbaru dengan peningkatan berkelanjutan pada akurasi dan kecepatan. YOLOv5 dan YOLOv8 saat ini banyak digunakan dalam aplikasi produksi.

Evaluasi Object Detection

  • Intersection over Union (IoU):

    Mengukur tingkat tumpang tindih antara bounding box hasil prediksi dan bounding box ground truth. Nilai IoU berada pada rentang 0 hingga 1, dengan ambang batas umum sebesar 0.5 untuk menentukan deteksi yang benar.

  • Precision:

    Menunjukkan proporsi bounding box hasil prediksi yang benar dibandingkan seluruh prediksi yang dihasilkan.

  • Recall:

    Menunjukkan proporsi objek sebenarnya yang berhasil terdeteksi oleh model.

  • mAP (mean Average Precision):

    Merupakan metrik utama dalam object detection yang menghitung rata-rata average precision dari setiap kelas objek. mAP@0.5 menggunakan ambang IoU 0.5, sedangkan mAP@0.5:0.95 merupakan rata-rata dari beberapa ambang IoU.

Proyek: Deteksi Alat Pelindung Diri (APD)

Deteksi APD merupakan penerapan penting dari object detection dalam konteks keselamatan kerja. Sistem ini bertujuan untuk mendeteksi secara otomatis apakah pekerja menggunakan alat pelindung diri yang diwajibkan seperti helm, rompi keselamatan, sarung tangan, kacamata pelindung, dan sepatu keselamatan. Otomatisasi ini penting untuk memastikan kepatuhan terhadap peraturan keselamatan dan mencegah kecelakaan kerja.

Motivasi dan Tujuan Proyek

Kecelakaan kerja sering terjadi akibat ketidakpatuhan terhadap prosedur keselamatan. Pemantauan manual oleh petugas keselamatan memiliki keterbatasan dan rentan terhadap kesalahan manusia. Sistem deteksi APD otomatis dapat menyediakan pemantauan real-time, memberikan peringatan instan terhadap pelanggaran, mencatat tingkat kepatuhan, serta secara signifikan menurunkan risiko kecelakaan kerja. Sistem ini sangat relevan untuk industri seperti konstruksi, manufaktur, pertambangan, serta minyak dan gas.

Dataset dan Preprocessing

Untuk melatih model deteksi APD, dibutuhkan dataset yang berisi gambar atau cuplikan video pekerja dalam berbagai kondisi, baik menggunakan maupun tidak menggunakan APD. Dataset harus diberi anotasi bounding box dan label untuk setiap item APD. Tahap preprocessing meliputi penyesuaian ukuran gambar, normalisasi, serta augmentasi data seperti rotasi, penyesuaian kecerahan, dan flipping untuk meningkatkan jumlah data dan ketahanan model.

Classes dalam Deteksi APD

  • Helmet/Hard Hat:

    Melindungi kepala dari benda jatuh atau benturan. Sangat penting di lokasi konstruksi.

  • Safety Vest:

    Pakaian dengan visibilitas tinggi untuk memastikan pekerja mudah terlihat, terutama pada kondisi cahaya rendah.

  • Safety Glasses/Goggles:

    Melindungi mata dari serpihan, bahan kimia, atau cahaya terang.

  • Gloves:

    Melindungi tangan dari luka, bahan kimia, panas, atau bahaya listrik.

  • Safety Boots:

    Melindungi kaki dari benda berat, material tajam, atau bahaya listrik.

  • Mask/Respirator:

    Melindungi sistem pernapasan dari debu, asap, atau gas berbahaya.

Arsitektur Model untuk Deteksi APD

Arsitektur YOLO sangat cocok untuk deteksi APD karena kemampuannya dalam pemrosesan real-time. Model dapat diterapkan pada perangkat edge atau diintegrasikan dengan sistem CCTV yang sudah ada. Arsitektur YOLO terdiri dari backbone untuk ekstraksi fitur, neck untuk penggabungan fitur, dan head untuk proses deteksi.

Training Process

  1. Data Preparation:

    Membagi dataset menjadi data training, validation, dan testing dengan proporsi yang seimbang.

  2. Model Configuration:

    Mengonfigurasi model YOLO sesuai jumlah kelas, ukuran input gambar, dan hyperparameter.

  3. Transfer Learning:

    Menggunakan bobot pre-trained untuk mempercepat proses pelatihan dan meningkatkan performa model.

  4. Training:

    Melatih model menggunakan GPU serta memantau metrik pelatihan untuk menghindari overfitting.

  5. Evaluation:

    Menguji model pada data yang belum pernah dilihat dan menganalisis performa setiap kelas.

Tantangan dalam Deteksi APD

  • Occlusion:

    Beberapa APD dapat tertutup sebagian oleh objek lain atau orang lain.

  • Varying Lighting Conditions:

    Perbedaan kondisi pencahayaan pada area kerja dapat mempengaruhi hasil deteksi.

  • Different Angles dan Poses:

    Posisi dan sudut tubuh pekerja yang beragam menambah kompleksitas deteksi.

  • Small Object Detection:

    Beberapa APD berukuran kecil sehingga lebih sulit dideteksi.

  • Class Imbalance:

    Jumlah data antar kelas APD tidak selalu seimbang dan memerlukan penanganan khusus.

Deployment dan Integration

Model yang telah dilatih dapat diterapkan pada perangkat edge, sistem berbasis cloud, maupun aplikasi mobile. Integrasi sistem mencakup koneksi dengan infrastruktur CCTV, pengaturan sistem peringatan otomatis, serta pencatatan pelanggaran untuk kebutuhan pelaporan dan evaluasi keselamatan. Model juga dapat terus diperbarui menggunakan data baru untuk meningkatkan performa.

Pertimbangan Etika

Penerapan sistem deteksi APD harus memperhatikan aspek etika, seperti perlindungan privasi pekerja, transparansi penggunaan sistem, serta memastikan bahwa teknologi digunakan untuk meningkatkan keselamatan, bukan sebagai alat pengawasan yang bersifat menghukum.

Dampak dan manfaat

  • Improved Safety:

    Meningkatkan keselamatan kerja melalui pemantauan kepatuhan yang konsisten.

  • Cost Reduction:

    Mengurangi biaya akibat kecelakaan kerja dan downtime operasional.

  • Scalability:

    Mampu memantau banyak lokasi secara bersamaan tanpa kelelahan manusia.

  • Data-Driven Insights:

    Menyediakan data analitik untuk mendukung pengambilan keputusan.

  • Real-time Alerts:

    Memberikan peringatan secara langsung untuk tindakan korektif.
