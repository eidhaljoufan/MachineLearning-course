Pertemuan 4 — K-Nearest Neighbors (KNN)

K-Nearest Neighbors (KNN) adalah algoritma supervised learning non-parametrik yang digunakan untuk tugas klasifikasi dan regresi. KNN bekerja berdasarkan prinsip sederhana: sebuah data point akan diklasifikasikan berdasarkan mayoritas kelas dari K tetangga terdekatnya dalam ruang fitur. Algoritma ini termasuk dalam kategori instance-based learning atau lazy learning karena tidak melakukan fase training eksplisit, melainkan menyimpan seluruh training data dan melakukan komputasi saat prediksi.

Konsep Dasar KNN

KNN mengoperasikan asumsi fundamental bahwa data points yang memiliki karakteristik serupa cenderung berada dalam jarak yang berdekatan dalam ruang fitur multidimensional. Ketika model menerima input baru, algoritma akan menghitung jarak antara input tersebut dengan seluruh data point dalam training set, kemudian memilih K tetangga terdekat untuk menentukan output prediksi.

Cara Kerja Algoritma KNN

Proses prediksi KNN dapat didekomposisi menjadi langkah-langkah sistematis berikut:

  1. Load Training Data:

    Menyimpan seluruh dataset training beserta labelnya dalam memori untuk digunakan saat prediksi.

  2. Tentukan Nilai K:

    Memilih jumlah tetangga terdekat (K) yang akan dipertimbangkan dalam proses voting atau averaging.

  3. Hitung Jarak:

    Untuk setiap data point baru, hitung jarak antara point tersebut dengan semua data dalam training set menggunakan metrik jarak tertentu.

  4. Identifikasi K Tetangga Terdekat:

    Urutkan semua data berdasarkan jarak dari yang terkecil, lalu pilih K data points dengan jarak terdekat.

  5. Voting/Averaging:

    Untuk klasifikasi, lakukan majority voting dari label K tetangga. Untuk regresi, hitung rata-rata nilai dari K tetangga.

  6. Output Prediksi:

    Kembalikan kelas (klasifikasi) atau nilai kontinu (regresi) sebagai hasil prediksi final.

Parameter K dan Dampaknya

Nilai K merupakan hyperparameter krusial yang menentukan performa model KNN. Pemilihan K yang tepat sangat bergantung pada karakteristik dataset dan kompleksitas masalah.

  • K Kecil (misal K=1 atau K=3):

    Model menjadi sangat sensitif terhadap noise dan outlier dalam data. Decision boundary menjadi kompleks dan fleksibel, meningkatkan risiko overfitting. Model dapat menangkap pola detail tetapi kurang stabil terhadap variasi kecil dalam data.

  • K Besar (misal K=50 atau K=100):

    Model menjadi lebih robust terhadap noise karena melibatkan lebih banyak tetangga dalam voting. Decision boundary menjadi lebih smooth dan sederhana, namun dapat menyebabkan underfitting jika K terlalu besar. Model mungkin kehilangan kemampuan untuk menangkap pola lokal yang penting.

  • K Optimal:

    Biasanya ditentukan melalui cross-validation. Aturan praktis adalah menggunakan K = √N dimana N adalah jumlah data training, namun ini hanya guideline awal. Untuk binary classification, gunakan K ganjil untuk menghindari tie dalam voting.

Metrik Jarak dalam KNN

Pemilihan metrik jarak mempengaruhi bagaimana KNN mengukur "kedekatan" antar data points. Berikut adalah metrik yang paling umum digunakan:

  • Euclidean Distance:

    Jarak garis lurus antara dua point dalam ruang Euclidean. Paling umum digunakan dan cocok untuk data numerik kontinu. Sensitif terhadap perbedaan skala antar fitur, sehingga normalisasi diperlukan.

  • Manhattan Distance:

    Jarak yang diukur dengan menjumlahkan perbedaan absolut setiap dimensi (seperti jarak yang ditempuh dalam grid kota). Lebih robust terhadap outlier dibanding Euclidean. Cocok untuk data high-dimensional atau sparse.

  • Minkowski Distance:

    Generalisasi dari Euclidean dan Manhattan dengan parameter p. Ketika p=1 menghasilkan Manhattan, p=2 menghasilkan Euclidean. Memberikan fleksibilitas dalam menyesuaikan karakteristik jarak dengan domain problem.

  • Hamming Distance:

    Digunakan untuk data kategorikal, menghitung jumlah posisi dimana dua string berbeda. Cocok untuk aplikasi seperti text classification atau genetic sequence comparison.

Kelebihan KNN

  • Sederhana dan Intuitif:

    Konsep algoritma mudah dipahami dan diimplementasikan tanpa memerlukan pengetahuan matematis yang kompleks.

  • No Training Phase:

    Tidak memerlukan fase training eksplisit sehingga sangat cepat untuk mempersiapkan model dengan data baru.

  • Adaptif terhadap Data Baru:

    Dapat langsung mengakomodasi data training baru tanpa perlu rebuild model dari awal.

  • Multi-Class Support:

    Secara natural dapat menangani masalah klasifikasi dengan banyak kelas tanpa modifikasi khusus.

  • Non-Linear Decision Boundary:

    Mampu membentuk decision boundary yang kompleks dan non-linear tanpa asumsi distribusi data.

Kekurangan KNN

  • Computational Cost Tinggi pada Prediksi:

    Harus menghitung jarak ke semua training points untuk setiap prediksi, menjadikannya lambat pada dataset besar (O(n) complexity).

  • Memory Intensive:

    Menyimpan seluruh training dataset dalam memori, tidak efisien untuk big data applications.

  • Sensitif terhadap Feature Scaling:

    Fitur dengan skala besar akan mendominasi perhitungan jarak. Feature normalization atau standardization adalah mandatory.

  • Curse of Dimensionality:

    Performa menurun drastis pada data high-dimensional karena konsep "jarak terdekat" menjadi tidak bermakna ketika dimensi meningkat.

  • Sensitif terhadap Irrelevant Features:

    Fitur yang tidak relevan dapat mengacaukan perhitungan jarak dan menurunkan akurasi. Feature selection menjadi sangat penting.

  • Imbalanced Data Problem:

    Kelas mayoritas cenderung mendominasi voting, menyebabkan bias prediksi pada kelas dengan sampel lebih sedikit.

Aplikasi KNN

KNN telah diimplementasikan secara luas dalam berbagai domain aplikasi praktis:

  • Recommendation Systems:

    Menemukan user atau item dengan preferensi serupa untuk memberikan rekomendasi produk atau konten (collaborative filtering).

  • Pattern Recognition:

    Pengenalan tulisan tangan, face recognition, dan fingerprint identification dengan membandingkan fitur visual.

  • Medical Diagnosis:

    Klasifikasi penyakit berdasarkan similarity gejala atau parameter medis pasien dengan historical records.

  • Credit Rating:

    Menilai kelayakan kredit dengan membandingkan profil calon debitur dengan historical data nasabah.

  • Anomaly Detection:

    Identifikasi data point yang memiliki jarak jauh dari semua tetangganya sebagai potential outlier atau fraud.

Best Practices dalam Implementasi KNN

  • Feature Scaling:

    Selalu lakukan normalisasi atau standardisasi fitur sebelum menerapkan KNN untuk memastikan semua fitur berkontribusi secara proporsional.

  • Dimensionality Reduction:

    Gunakan teknik seperti PCA atau feature selection untuk mengurangi dimensi dan mengatasi curse of dimensionality.

  • Cross-Validation untuk K:

    Gunakan k-fold cross-validation untuk menemukan nilai K optimal yang memberikan best generalization performance.

  • Efficient Data Structures:

    Implementasikan struktur data seperti KD-Tree atau Ball Tree untuk mempercepat nearest neighbor search pada dataset besar.

  • Weighted KNN:

    Pertimbangkan untuk memberikan bobot lebih tinggi pada tetangga yang lebih dekat (distance-weighted voting) untuk meningkatkan akurasi.
