Pertemuan 19 — Real-Time Object Detection (Pen–Book Detection)

Real-time object detection merupakan salah satu penerapan penting dalam computer vision yang bertujuan untuk mendeteksi dan melokalisasi objek secara langsung (live) dari input video atau kamera. Berbeda dengan image classification yang hanya menentukan kelas gambar, object detection memiliki dua tugas utama sekaligus, yaitu mengenali apa objeknya dan di mana posisi objek tersebut dalam bentuk bounding box.

Pada pertemuan ini, fokus deteksi diarahkan pada objek pulpen (pen) dan buku (book). Kedua objek tersebut tergolong small objects, sehingga menimbulkan tantangan tersendiri dalam proses training dan pemilihan model deteksi yang tepat.

Pengenalan Object Detection dengan YOLO

YOLO (You Only Look Once) adalah algoritma object detection yang dirancang untuk kecepatan dan efisiensi tinggi. YOLO melakukan prediksi bounding box dan class probability dalam satu kali proses inferensi, sehingga sangat cocok untuk kebutuhan real-time detection seperti CCTV, autonomous system, dan webcam-based detection.

Dalam praktik ini digunakan YOLOv8, versi terbaru dari keluarga YOLO yang menawarkan peningkatan pada akurasi, stabilitas training, dan kemudahan integrasi dengan Python dan Jupyter Notebook.

Dataset Pen–Book Detection

Sebelum masuk ke tahap training dan pengujian model, dataset harus disiapkan dengan struktur yang benar. Dataset diperoleh dari Google Drive yang disediakan oleh dosen dengan nama PenBookDetection-1.

Langkah Persiapan Dataset:

  1. Download Dataset:

    Unduh dataset PenBookDetection-1 dari Google Drive yang diberikan dosen.

  2. Simpan ke Project:

    Simpan dataset ke dalam folder datasets/PenBookDetection-1.

  3. Periksa Struktur Direktori:

    Pastikan folder train, val, dan testimages dan labels.

  4. Cek data.yaml:

    Pastikan file data.yaml berisi path direktori train, val, dan test yang benar.

Struktur Dataset YOLO

YOLO sangat bergantung pada struktur direktori dataset. Kesalahan path atau struktur folder dapat menyebabkan training gagal meskipun file dataset sudah tersedia.

Perbandingan Model YOLO untuk Small Object Detection

Model YOLO Karakteristik Kelebihan Kekurangan Rekomendasi

Lingkungan Praktik dan Kebutuhan Hardware

Training model object detection membutuhkan resource komputasi yang cukup besar, terutama ketika dataset berisi banyak gambar dan jumlah epoch tinggi. Oleh karena itu, pemilihan lingkungan praktik sangat berpengaruh terhadap kelancaran proses training.

Praktik Menggunakan Jupyter Notebook (Windows Lokal)

Spesifikasi Minimum yang Disarankan:

  • GPU:

    NVIDIA dengan CUDA support (minimal GTX 1660 atau setara).

  • VRAM:

    Minimal 6 GB.

  • RAM:

    Minimal 16 GB.

  • Software:

    CUDA, cuDNN, Python, Jupyter Notebook.

Tanpa GPU, training masih dapat dijalankan menggunakan CPU, namun waktu yang dibutuhkan bisa sangat lama dan tidak efisien untuk menyelesaikan epoch training secara penuh.

Alternatif Praktik: Google Colab

Jika perangkat lokal tidak memenuhi spesifikasi, Google Colab menjadi solusi yang sangat direkomendasikan. Colab menyediakan GPU secara gratis dan siap digunakan tanpa konfigurasi CUDA manual.

  • Kelebihan:

    Mendukung GPU, mudah digunakan, cocok untuk training YOLO.

  • Kekurangan:

    Session terbatas dan file perlu di-upload ulang jika session berakhir.

Tujuan Praktik Pertemuan 19

Melalui pertemuan ini, diharapkan dapat memahami alur lengkap real-time object detection mulai dari persiapan dataset, pemilihan model YOLO yang sesuai, hingga kesiapan lingkungan komputasi sebelum masuk ke tahap praktik implementasi di Jupyter Notebook atau Google Colab.

Best.pt yang sudah didapatkan dari hasil training dataset tersebut masih kurang akurat, karena ketika mendeteksi pulpen yang sedang saya pegang itu mesin masih menunjukkan keragu-raguan, yaitu 0.26. Yang mana artinya model tersebut hanya 26% yakin bahwa objek yang dideteksi adalah pulpen.
