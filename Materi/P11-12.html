Pertemuan 11 & 12 — Unsupervised Learning

Unsupervised Learning adalah paradigma pembelajaran mesin dimana model dilatih menggunakan dataset yang tidak memiliki label atau target eksplisit. Berbeda dengan supervised learning yang memerlukan pasangan input-output (X, Y), unsupervised learning hanya bekerja dengan input data (X) dan bertujuan untuk menemukan struktur tersembunyi, pola intrinsik, atau representasi yang bermakna dari data tersebut. Paradigma ini sangat powerful untuk eksplorasi data, menemukan insight yang tidak terduga, dan sebagai tahap preprocessing sebelum supervised learning.

Karakteristik Unsupervised Learning

Unsupervised learning memiliki karakteristik unik yang membedakannya dari paradigma pembelajaran lainnya:

  • No Labels Required:

    Tidak memerlukan proses labeling data yang mahal dan time-consuming. Model belajar langsung dari struktur data mentah tanpa guidance eksplisit.

  • Pattern Discovery:

    Fokus pada penemuan pola, struktur, atau hubungan yang tidak terlihat secara eksplisit dalam data. Model mengekstraksi informasi laten yang mungkin tidak disadari oleh manusia.

  • Exploratory Nature:

    Sering digunakan sebagai tahap eksplorasi awal untuk memahami karakteristik dataset sebelum menerapkan teknik supervised learning.

  • Subjective Evaluation:

    Tidak ada ground truth untuk membandingkan hasil, sehingga evaluasi performa sering bersifat subjektif atau menggunakan metrik internal seperti silhouette score atau inertia.

Kategori Utama Unsupervised Learning

Unsupervised learning dapat diklasifikasikan menjadi beberapa kategori berdasarkan tujuan dan metode yang digunakan:

1. Clustering (Pengelompokan)

Clustering adalah proses mengelompokkan data points ke dalam clusters (kelompok) berdasarkan similarity atau proximity mereka dalam ruang fitur. Data points dalam cluster yang sama memiliki karakteristik yang mirip, sementara data points dari cluster berbeda memiliki karakteristik yang berbeda.

Tujuan: Menemukan struktur natural dalam data dengan mempartisi data menjadi groups yang homogen tanpa label yang telah ditentukan sebelumnya.

Algoritma Populer:

  • K-Means:

    Algoritma partitioning yang membagi data menjadi K clusters dengan meminimalkan within-cluster variance. Fast dan scalable, cocok untuk cluster yang spherical dan well-separated.

  • Hierarchical Clustering:

    Membangun hierarki clusters dalam bentuk dendrogram. Dapat berupa agglomerative (bottom-up) atau divisive (top-down). Tidak perlu specify jumlah cluster di awal.

  • DBSCAN:

    Density-based clustering yang dapat menemukan cluster dengan bentuk arbitrary dan mengidentifikasi outliers. Robust terhadap noise dan tidak memerlukan predefined number of clusters.

  • Gaussian Mixture Models (GMM):

    Model probabilistik yang mengasumsikan data dihasilkan dari mixture of Gaussian distributions. Lebih fleksibel dari K-Means dan dapat model cluster dengan elliptical shapes.

Aplikasi: Customer segmentation untuk marketing, image segmentation, anomaly detection, document clustering, gene sequence analysis, dan social network analysis.

2. Dimensionality Reduction (Reduksi Dimensi)

Dimensionality reduction adalah teknik untuk mengurangi jumlah fitur (dimensi) dalam dataset sambil mempertahankan informasi penting sebanyak mungkin. Teknik ini sangat crucial untuk mengatasi curse of dimensionality dan memfasilitasi visualisasi data high-dimensional.

Tujuan: Mentransformasi data dari ruang high-dimensional ke ruang low-dimensional dengan meminimalkan information loss, mempercepat komputasi, dan mengurangi overfitting.

Metode Populer:

  • Principal Component Analysis (PCA):

    Teknik linear yang menemukan orthogonal axes (principal components) yang menangkap maximum variance dalam data. Component pertama menangkap variance terbesar, component kedua menangkap variance terbesar kedua yang orthogonal terhadap yang pertama, dan seterusnya.

  • t-SNE (t-Distributed Stochastic Neighbor Embedding):

    Teknik non-linear yang sangat effective untuk visualisasi data high-dimensional ke 2D atau 3D. Mempertahankan local structure dengan baik, cocok untuk exploratory data analysis.

  • Autoencoders:

    Neural network architecture yang belajar compressed representation dari data melalui encoding-decoding process. Dapat menangkap non-linear relationships dan digunakan untuk feature extraction.

  • Linear Discriminant Analysis (LDA):

    Meskipun supervised method, LDA sering digunakan untuk dimensionality reduction dengan memaksimalkan separability antar classes.

Aplikasi: Data visualization, feature extraction, noise reduction, data compression, preprocessing untuk machine learning models, dan image processing.

3. Association Rule Learning

Association rule learning menemukan interesting relationships atau associations antara variables dalam large databases. Teknik ini mengidentifikasi aturan-aturan dalam bentuk "if X then Y" yang menggambarkan co-occurrence patterns dalam data.

Tujuan: Menemukan frequent patterns, associations, atau correlations dalam transactional databases atau large datasets.

Konsep Kunci:

  • Support:

    Frekuensi kemunculan itemset dalam dataset. Mengukur seberapa sering kombinasi item muncul bersamaan.

  • Confidence:

    Probabilitas kondisional bahwa Y terjadi given X terjadi. Mengukur reliability dari aturan.

  • Lift:

    Rasio observed support terhadap expected support jika X dan Y independen. Nilai > 1 mengindikasikan positive correlation.

Algoritma: Apriori algorithm, FP-Growth (Frequent Pattern Growth), dan Eclat algorithm.

Aplikasi: Market basket analysis (recommendation systems), web usage mining, cross-selling strategies, catalog design, dan medical diagnosis.

4. Anomaly Detection

Anomaly detection atau outlier detection bertujuan mengidentifikasi data points yang significantly berbeda dari mayoritas data. Anomalies adalah observations yang menyimpang dari normal behavior atau expected patterns.

Tujuan: Menemukan rare items, events, atau observations yang mencurigakan dengan pola yang sangat berbeda dari data normal.

Teknik: Statistical methods, clustering-based approaches (data points jauh dari semua clusters), density-based methods, dan isolation forests.

Aplikasi: Fraud detection dalam financial transactions, network intrusion detection, system health monitoring, quality control manufacturing, dan medical diagnosis untuk penyakit langka.

Kelebihan Unsupervised Learning

  • No Labeling Cost:

    Tidak memerlukan biaya dan waktu untuk labeling data yang mahal. Dapat langsung bekerja dengan raw data.

  • Discover Hidden Patterns:

    Dapat menemukan struktur atau insight yang tidak terduga dan tidak terdeteksi oleh analisis manual.

  • Scalability:

    Dapat diterapkan pada dataset besar tanpa memerlukan labeled data yang proporsinya sama besar.

  • Flexibility:

    Cocok untuk exploratory data analysis dan tidak memerlukan predefined categories atau outcomes.

Kekurangan Unsupervised Learning

  • Subjective Interpretation:

    Hasil sering memerlukan domain expertise untuk interpretasi dan validasi karena tidak ada ground truth.

  • Difficult Evaluation:

    Tidak ada clear metrics untuk mengukur performa secara objektif. Evaluasi bergantung pada business context.

  • Less Accurate:

    Generally kurang akurat dibanding supervised learning untuk predictive tasks karena lack of explicit guidance.

  • Computational Complexity:

    Beberapa metode seperti hierarchical clustering atau t-SNE dapat sangat computationally expensive pada large datasets.

  • Sensitive to Parameters:

    Hasil sangat bergantung pada hyperparameter yang dipilih (seperti K dalam K-Means) dan sering memerlukan trial-and-error.

Kapan Menggunakan Unsupervised Learning

  • No Labeled Data Available:

    Ketika labeling data tidak feasible, terlalu mahal, atau memerlukan expertise khusus yang langka.

  • Data Exploration:

    Sebagai tahap awal untuk memahami struktur data sebelum menerapkan supervised learning atau mengambil keputusan bisnis.

  • Feature Engineering:

    Untuk generate new features atau reduce dimensionality sebagai preprocessing step untuk supervised models.

  • Unknown Patterns:

    Ketika kita tidak tahu apa yang kita cari dan ingin membiarkan data "berbicara sendiri" untuk reveal hidden structures.
