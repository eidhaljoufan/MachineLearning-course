Pertemuan 13 — Clustering

Clustering adalah teknik unsupervised learning yang bertujuan untuk mengelompokkan data points ke dalam clusters berdasarkan tingkat kemiripan (similarity) atau kedekatan (proximity) antar data. Data points yang berada dalam satu cluster memiliki karakteristik yang serupa, sedangkan data points yang berada pada cluster berbeda memiliki karakteristik yang tidak serupa. Clustering merupakan salah satu metode paling fundamental dan paling banyak digunakan dalam machine learning untuk menemukan struktur alami dalam data tanpa memerlukan label yang telah ditentukan sebelumnya.

Konsep Dasar Clustering

Clustering bekerja dengan mengukur tingkat kemiripan atau jarak antar data points dalam ruang fitur multidimensional. Tujuan utama dari proses ini adalah memaksimalkan kemiripan dalam satu cluster (intra-cluster similarity) dan meminimalkan kemiripan antar cluster yang berbeda (inter-cluster similarity). Proses clustering dilakukan secara iteratif hingga mencapai kondisi optimal, di mana penugasan data points ke dalam clusters sudah stabil atau memenuhi kriteria konvergensi tertentu.

Perbandingan Algoritma Clustering

Algoritma Cara Kerja Kelebihan Kekurangan Use Case

Cepat, scalable, mudah diimplementasikan, efisien untuk dataset besar, cocok untuk cluster berbentuk spherical. Harus menentukan nilai K di awal, sensitif terhadap inisialisasi awal, tidak cocok untuk cluster non-spherical, sensitif terhadap outliers. Segmentasi pelanggan, kompresi gambar, clustering dokumen.

Tidak perlu menentukan K di awal, menghasilkan dendrogram yang informatif, cocok untuk data dengan struktur hierarkis alami. 1. K-Means Clustering

K-Means merupakan algoritma clustering paling populer yang bekerja dengan pendekatan partitioning. Algoritma ini membagi dataset menjadi K clusters dengan tujuan meminimalkan within-cluster sum of squares (WCSS), yaitu total jarak kuadrat antara setiap data point dengan centroid dari cluster tempatnya berada.

Langkah-langkah K-Means:

  1. Inisialisasi:

    Memilih K centroid secara acak atau menggunakan metode seperti K-Means++ untuk inisialisasi yang lebih optimal.

  2. Assignment:

    Menetapkan setiap data point ke cluster dengan centroid terdekat berdasarkan jarak Euclidean.

  3. Update:

    Menghitung ulang centroid setiap cluster sebagai nilai rata-rata dari seluruh data points yang berada dalam cluster tersebut.

  4. Iterasi:

    Mengulangi langkah assignment dan update hingga centroid tidak mengalami perubahan signifikan atau mencapai jumlah iterasi maksimum.

Menentukan Nilai K Optimal: Dapat menggunakan Elbow Method (plot WCSS terhadap K dan mencari titik “siku”) atau Silhouette Score yang mengukur seberapa baik sebuah data point cocok dengan cluster-nya.

2. Hierarchical Clustering

Hierarchical clustering membangun struktur hierarki cluster yang dapat divisualisasikan menggunakan dendrogram. Terdapat dua pendekatan utama, yaitu agglomerative (bottom-up) yang dimulai dari setiap data point sebagai cluster tersendiri kemudian digabungkan secara bertahap, serta divisive (top-down) yang dimulai dari satu cluster besar lalu dipecah secara iteratif.

Metode Linkage:

  • Single Linkage:

    Jarak antar cluster ditentukan oleh jarak minimum antara dua data points dari cluster yang berbeda. Metode ini cenderung menghasilkan cluster memanjang.

  • Complete Linkage:

    Jarak antar cluster ditentukan oleh jarak maksimum antara dua data points dari cluster yang berbeda. Menghasilkan cluster yang lebih kompak.

  • Average Linkage:

    Jarak antar cluster dihitung sebagai rata-rata jarak seluruh pasangan data points dari cluster yang berbeda.

  • Ward's Method:

    Mencari penggabungan cluster yang meminimalkan peningkatan variansi total dalam cluster.

3. DBSCAN (Density-Based Spatial Clustering)

DBSCAN merupakan algoritma clustering berbasis kepadatan yang mampu menemukan cluster dengan bentuk arbitrer serta secara otomatis mengidentifikasi outliers sebagai noise. Algoritma ini berangkat dari asumsi bahwa cluster merupakan area dengan kepadatan data tinggi yang dipisahkan oleh area dengan kepadatan rendah.

Konsep Kunci:

  • Epsilon (ε):

    Radius neighborhood untuk setiap data point, di mana data points dalam radius ini dianggap sebagai tetangga.

  • MinPoints:

    Jumlah minimum data points yang harus berada dalam ε-neighborhood untuk membentuk area dengan kepadatan tinggi.

  • Core Points:

    Data points yang memiliki setidaknya MinPoints tetangga dalam radius ε.

  • Border Points:

    Data points yang bukan core point tetapi berada dalam neighborhood dari core point.

  • Noise Points:

    Data points yang bukan core maupun border dan dianggap sebagai outliers.

4. Gaussian Mixture Models (GMM)

Gaussian Mixture Models (GMM) merupakan model probabilistik yang mengasumsikan data dihasilkan dari campuran beberapa distribusi Gaussian. Berbeda dengan K-Means yang melakukan hard assignment, GMM menggunakan soft assignment, di mana setiap data point memiliki probabilitas keanggotaan pada setiap cluster.

Expectation-Maximization (EM) Algorithm:

  1. Initialization:

    Menginisialisasi parameter model seperti mean, covariance, dan mixing coefficients untuk setiap distribusi Gaussian.

  2. E-Step (Expectation):

    Menghitung probabilitas setiap data point berasal dari masing-masing Gaussian component.

  3. M-Step (Maximization):

    Memperbarui parameter model untuk memaksimalkan likelihood berdasarkan probabilitas saat ini.

  4. Convergence:

    Mengulangi E-step dan M-step hingga nilai log-likelihood konvergen atau mencapai batas iterasi maksimum.

Evaluasi Clustering

Karena clustering termasuk ke dalam unsupervised learning, evaluasi performanya tidak sesederhana supervised learning. Beberapa metrik yang umum digunakan antara lain:

  • Silhouette Score:

    Mengukur tingkat kemiripan sebuah data point dengan cluster-nya sendiri dibandingkan dengan cluster lain.

  • Davies-Bouldin Index:

    Rasio antara jarak dalam cluster terhadap jarak antar cluster. Nilai yang lebih rendah menunjukkan hasil clustering yang lebih baik.

  • Calinski-Harabasz Index:

    Perbandingan antara dispersi antar cluster dan dispersi dalam cluster. Nilai yang lebih tinggi menunjukkan kualitas clustering yang lebih baik.

  • Inertia (WCSS):

    Total jarak kuadrat dari setiap data point ke centroid cluster-nya, khusus digunakan pada K-Means.

Aplikasi Praktis Clustering

  • Customer Segmentation:

    Mengelompokkan pelanggan berdasarkan perilaku pembelian, demografi, atau preferensi untuk strategi pemasaran yang lebih tepat sasaran.

  • Image Segmentation:

    Membagi gambar menjadi region yang bermakna untuk berbagai tugas computer vision.

  • Anomaly Detection:

    Data points yang tidak termasuk ke dalam cluster manapun atau hanya membentuk cluster kecil dapat dianggap sebagai anomali.

  • Document Organization:

    Mengelompokkan dokumen atau artikel berdasarkan kemiripan topik untuk sistem pencarian informasi.

  • Recommendation Systems:

    Clustering pengguna atau item untuk mendukung collaborative filtering.

  • Genomics:

    Mengelompokkan data ekspresi gen untuk mengidentifikasi pola biologis atau klasifikasi penyakit.

Best Practices dalam Clustering

  • Feature Scaling:

    Melakukan normalisasi atau standardisasi fitur sebelum clustering, terutama untuk metode berbasis jarak.

  • Dimensionality Reduction:

    Menggunakan PCA atau t-SNE untuk mengurangi dimensi data berdimensi tinggi.

  • Try Multiple Algorithms:

    Tidak ada algoritma clustering yang selalu paling baik. Perlu mencoba beberapa metode dan membandingkan hasilnya.

  • Domain Knowledge:

    Memvalidasi hasil clustering menggunakan pengetahuan domain agar hasilnya relevan secara konteks.

  • Visualize Results:

    Memvisualisasikan cluster menggunakan scatter plot, dendrogram, atau teknik reduksi dimensi.
