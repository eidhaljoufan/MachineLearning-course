Pertemuan 7 — Regresi Linear

Linear Regression adalah teknik pemodelan statistik yang digunakan untuk memprediksi nilai variabel dependen (target) berdasarkan hubungan linear dengan satu atau lebih variabel independen (fitur). Secara akademik, tujuan utamanya adalah menemukan garis regresi terbaik (line of best fit) yang meminimalkan jumlah kuadrat residu atau selisih antara nilai aktual dan prediksi.

Proses Linear Regression

Dalam siklus pengembangan model regresi, terdapat empat tahapan utama yang dilakukan secara berurutan untuk menghasilkan estimasi yang presisi:

  1. Modeling:

    Tahap konstruksi model berdasarkan basis data yang tersedia dengan menghitung nilai koefisien regresi (β) yang meminimalkan error (sering disebut sebagai metode Ordinary Least Squares, OLS).

  2. Training:

    Proses induksi model menggunakan dataset pelatihan untuk menemukan nilai optimal dari koefisien β. Pada tahap ini, algoritma belajar mengenali pola linear dan kekuatan korelasi antar variabel.

  3. Evaluation:

    Asesmen terhadap performa model untuk mengukur sejauh mana model mampu melakukan prediksi pada data baru. Ukuran umum yang digunakan adalah R2 (koefisien determinasi), Mean Squared Error (MSE), dan lainnya.

Taksonomi Metode Regresi Linear

Berikut adalah klasifikasi metode regresi berdasarkan kompleksitas data dan tujuan optimasi model:

No. Nama Metode Definisi Rumus Dasar Studi Kasus
1 Simple Linear Regression Model dengan satu variabel independen tunggal. y = β0 + β1x + ε Prediksi harga rumah berdasarkan luas tanah.
2 Multiple Linear Regression Model yang melibatkan dua atau lebih variabel independen. y = β0 + β1x1 + β2x2 + … + βnxn + ε Prediksi harga berdasarkan ukuran, lokasi, dan usia bangunan.
3 Polynomial Regression Menangani hubungan non-linear dengan memangkatkan fitur. y = β0 + β1x1 + β2x2 + … + ε Prediksi pertumbuhan organisme terhadap waktu yang melengkung.
4 Ridge Regression Regresi dengan penalti L2 untuk mengatasi multikolinearitas. min ‖y − Xβ‖2 + α‖β‖2 Data dengan fitur yang saling berkorelasi sangat tinggi.
5 Lasso Regression Regresi dengan penalti L1 untuk seleksi fitur otomatis. min ‖y − Xβ‖2 + α‖β‖1 Dataset dengan fitur sangat banyak di mana hanya sedikit yang relevan.
6 Elastic Net Kombinasi penalti L1 dan L2 (Ridge + Lasso). Campuran Penalti L1 & L2
(min ‖y − Xβ‖2 + α1‖β‖1 + α2‖β‖2) 		Kebutuhan stabilitas Ridge sekaligus efisiensi Lasso.
7 Robust Regression Model yang tahan terhadap gangguan outlier ekstrem. Metode M-estimators / Huber Loss Dataset yang memiliki banyak data pencilan (outliers).
8 Stepwise Regression Seleksi fitur iteratif (Forward/Backward selection). Prosedur Seleksi Otomatis Mencari kombinasi fitur terbaik secara statistik.
