Pertemuan 10 — Decision Trees dan Integrasi Flask

Decision Tree adalah algoritma supervised learning yang menggunakan struktur hierarki seperti pohon untuk mengambil keputusan. Algoritma ini sangat populer di kalangan praktisi data karena sifatnya yang interpretable, artinya manusia dapat dengan mudah memahami logika di balik setiap prediksi yang dihasilkan oleh model.

Mekanisme Kerja Decision Tree

Dalam membangun pohon keputusan, algoritma melakukan pembagian data (splitting) secara rekursif berdasarkan fitur yang paling informatif. Proses ini melibatkan beberapa konsep kunci:

  • Root Node:

    Titik awal yang mewakili seluruh populasi data dan fitur pertama yang paling signifikan untuk membagi data.

  • Entropy & Information Gain:

    Metrik statistik yang digunakan untuk mengukur "kekacauan" data. Fitur dengan Information Gain tertinggi akan dipilih sebagai titik pemisah.

  • Gini Impurity:

    Indikator alternatif (sering digunakan oleh library Scikit-Learn) untuk mengukur seberapa sering elemen yang dipilih secara acak akan salah diklasifikasikan.

  • Leaf Node:

    Node akhir yang memberikan output prediksi (label kelas atau nilai kontinu) dan tidak dapat dibagi lagi.

K-Nearest Neighbors (KNN) secara Singkat

Berbeda dengan Decision Tree yang membangun aturan logis, KNN bekerja berdasarkan prinsip kemiripan jarak. Model ini mengklasifikasikan data baru dengan mencari k tetangga terdekat dalam ruang fitur menggunakan metrik seperti Euclidean Distance. KNN sangat efektif untuk data dengan pola lokal yang kuat namun memiliki biaya komputasi yang tinggi pada dataset besar.

Integrasi Model ke dalam Web Flask

Untuk mentransformasi model Machine Learning menjadi produk digital, kita menggunakan Flask, sebuah micro-framework berbasis Python. Proses integrasinya meliputi:

  1. Model Serialization:

    Menyimpan model yang telah dilatih (misal: Decision Tree) ke dalam format file .pkl menggunakan library Pickle atau Joblib.

  2. API Routing:

    Membuat route pada Flask yang menerima input data dari form HTML melalui metode POST.

  3. Inference:

    Memuat kembali model di dalam server Flask, melakukan prediksi terhadap input user, dan mengirimkan hasilnya kembali ke frontend untuk ditampilkan.

Implementasi Dasar Decision Tree

 from sklearn.tree import DecisionTreeClassifier from sklearn import tree import matplotlib.pyplot as plt

    Inisialisasi Model dengan kriteria Gini
    clf = DecisionTreeClassifier(criterion='gini', max_depth=3)

    Pelatihan Model
    clf.fit(X_train, y_train)

    Visualisasi Struktur Pohon
    plt.figure(figsize=(12,8)) tree.plot_tree(clf, filled=True, feature_names=feature_cols) plt.show()

Analisis Kelebihan dan Kekurangan

Aspek Kelebihan Kekurangan
Interpretabilitas Sangat mudah dijelaskan secara visual (White-box model). Gampang mengalami Overfitting jika pohon terlalu dalam.
Data Preparation Tidak membutuhkan normalisasi atau standardisasi data. Sensitif terhadap perubahan kecil pada data (Instabilitas).
Kompleksitas Mampu menangani fitur numerik dan kategorikal sekaligus. Bisa menghasilkan pohon yang sangat kompleks dan sulit dibaca.
