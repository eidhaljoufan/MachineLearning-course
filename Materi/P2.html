Pertemuan 2 — Data Preprocessing dalam Machine Learning

Data Preprocessing adalah tahapan krusial dalam siklus pengembangan model Machine Learning yang bertujuan untuk mentransformasi data mentah (raw data) menjadi format yang bersih dan kompatibel untuk diproses oleh algoritma. Kualitas representasi data secara langsung berkolerasi dengan performa generalisasi model yang dihasilkan.

1. Data Cleaning (Pembersihan Data)

Proses identifikasi dan koreksi terhadap data yang tidak akurat, tidak lengkap, atau tidak konsisten.

  • Handling Missing Values:

    Penanganan data yang hilang menggunakan teknik imputerasi (Mean, Median, Mode) atau penghapusan baris/kolom (Deletion).

  • Noise Reduction:

    Penghapusan outlier atau data pencilan yang dapat mendistorsi distribusi statistik data.

  • Consistency Check:

    Sinkronisasi format data (misal: penyeragaman format tanggal atau satuan ukur).

2. Data Transformation

Tahapan untuk mengubah skala atau distribusi fitur agar algoritma dapat melakukan konvergensi lebih cepat.

  • Normalization (Min-Max Scaling):

    Menskalakan data ke rentang 0 hingga 1.

  • Standardization (Z-score Scaling):

    Mengubah data sehingga memiliki rata-rata (mean) 0 dan standar deviasi 1.

  • Encoding:

    Mentransformasi data kategorikal menjadi representasi numerik (contoh: One-Hot Encoding atau Label Encoding).

3. Data Reduction

Teknik untuk menyederhanakan dataset dengan mengurangi jumlah fitur (variabel) tanpa menghilangkan informasi signifikan, guna menghindari Curse of Dimensionality.

  • Feature Selection:

    Memilih subset fitur yang paling relevan dengan target.

  • Feature Extraction:

    Menggabungkan beberapa fitur menjadi fitur baru yang lebih informatif (contoh: Principal Component Analysis/PCA).

Siklus Pengembangan dan Metodologi Machine Learning

Implementasi Machine Learning mengikuti alur kerja iteratif yang sistematis untuk memastikan model memiliki kemampuan generalisasi yang tinggi terhadap data baru. Berikut adalah dekomposisi langkah-langkah penyelesaiannya:

  1. Pengumpulan Data (Data Collection)

    Tahap akuisisi data yang relevan dari berbagai instrumen seperti database relasional, sensor IoT, Application Programming Interface (API), maupun repositori publik.

  2. Pemahaman Data (Data Understanding)

    Melakukan analisis eksploratif untuk memetakan struktur, format, dan karakteristik statistik data, termasuk identifikasi korelasi antar variabel dalam dataset.

  3. Pembersihan Data (Data Cleaning)

    Eradikasi anomali dataset melalui penghapusan redundansi (duplikat), mitigasi nilai yang hilang (missing values), dan standardisasi format yang inkonsisten.

  4. Preprocessing Data

    Transformasi fitur agar siap dikonsumsi algoritma, mencakup normalisasi skala, encoding variabel kategorikal, serta seleksi fitur relevan guna mereduksi dimensi data.

  5. Pemisahan Dataset (Dataset Splitting)

    Alokasi data menjadi subset pelatihan (training set) untuk konstruksi model dan subset pengujian (testing set) untuk validasi independen guna mencegah overfitting.

  6. Pemilihan Model (Model Selection)

    Determinasi algoritma yang paling kompatibel dengan tipologi masalah (Klasifikasi/Regresi) serta mempertimbangkan aspek interpretabilitas dan skala data.

  7. Pelatihan Model (Model Training)

    Proses induksi di mana model mengekstraksi pola dari data latih dengan mengoptimalkan parameter atau bobot (weights) untuk meminimalkan fungsi kerugian (loss function).

  8. Evaluasi Model (Model Evaluation)

    Asesmen performa model menggunakan metrik saintifik seperti Akurasi, Presisi, Recall, F1-Score, dan AUC pada data uji.

  9. Penyetelan Model (Model Tuning)

    Optimasi performa melalui penyetelan hiperparameter menggunakan teknik sistematis seperti Grid Search atau Random Search.

  10. Pengujian Model (Model Testing)

    Validasi akhir menggunakan data yang sepenuhnya baru (unseen data) untuk mensimulasikan performa model pada skenario dunia nyata.

  11. Penyempurnaan dan Implementasi (Deployment)

    Integrasi model ke dalam ekosistem produksi, mencakup pemantauan performa berkelanjutan dan pemeliharaan model agar tetap relevan terhadap perubahan distribusi data.

Setelah langkah-langkah ini selesai, model dapat diimplementasikan dalam produksi dan digunakan untuk membuat prediksi atau mengambil keputusan berdasarkan data baru. Penting untuk diingat bahwa langkah-langkah ini bersifat iteratif dan dapat melibatkan pengulangan dan penyesuaian ulang berdasarkan evaluasi dan kebutuhan yang muncul selama proses.
